# UpKlepsi-backend

**Backend:**

- Ecosistema en java.
- Base de datos MySQL.
- Uso de Spring Boot.
- Uso de Spring Security.
- Sistema de login.
- Sistema de permisos y roles.
- Gestor de dependencias en Maven.
- Sistema de links permanentes, donde el usuario puede elegir el tiempo para que expire o si quiere que sea infinito.
- EndPoints que sirvan los servicios para subir, borrar, actualizar, etc, mediante **API Rest**
